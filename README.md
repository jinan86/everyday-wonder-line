Entry for the [make.fun](https://make.fun/c/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3?utm_source=github&utm_medium=readme&utm_campaign=u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) competition **Everyday Wonder, Two Days to Find the Line** — one sentence, at most 200 characters, on a small moment of wonder in everyday life.

## The entry

> The tap drips once after I shut it off, as if the sink were finishing my sentence.

## How it works

`main.py` (Python 3.13) writes that single sentence to `/output/entry.txt`, after checking it is 1–200 characters and exactly one sentence. The run is fully deterministic: the same bytes every time.

```sh
python3 main.py
cat /output/entry.txt
```
